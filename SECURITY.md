# Security

## API keys

Never include a Cisco Meraki Dashboard API key in an issue, pull request, screenshot, log excerpt, sample file, or source-code commit.

If a key is exposed, revoke it in the Meraki Dashboard immediately and generate a replacement.

## Customer data

Generated CSV reports may contain organization names, network names, SSIDs, IDs, configuration details, and Dashboard links. Sanitize report data before attaching it to a public issue or repository.

## Reporting a problem

When reporting a bug, reproduce it with sanitized organization/network/SSID names whenever possible. Remove API keys and customer-identifying data before sharing logs.
